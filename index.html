HerjaHub

Team project · my scope below

A multi-vendor marketplace for Palestinian artisans. Craftspeople here make work worth buying but have almost no way to be found online, so sales stay local and small. HerjaHub gives an artisan a storefront, a product catalogue, and a direct line to customers.

  • Front-end, all of it. Designed and built every screen in JSP with hand-written CSS — no framework, no component library.
  • The customer side, end to end. Product catalogue, store directory, search, cart, order history, and profile management.
  • Role-based access. Separate permissions for customers and store owners, with registration, login, and real 401 / 403 / 404 pages instead of raw server errors.
  • AI-assisted search. Integrated an assistant so customers can describe what they want instead of guessing keywords.
  • Repository owner. Set the branching workflow for the team, reviewed incoming branches, and resolved the merge conflicts.
  • Deployment. Shipped it to an AWS EC2 instance running Apache Tomcat.
